### Design notes

- Scripture/talk buttons use Church universal links (`churchofjesuschrist.org/study…`) so they open in **Gospel Library** on iOS/Android when the app is installed.
- One integrated slideshow (not three) — teachers jump to Theme 1 / 2 / 3 via sections, or teach the whole arc.
- “Go deeper” boxes mirror Jax’s classroom style: place-yourself prompts, historical tension, distraction-as-opposition, praying while afraid.
